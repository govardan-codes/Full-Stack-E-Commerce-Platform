## 📖 Overview

ShopNow is a Full-Stack E-Commerce Platform built with **Core Java, Spring Boot, MySQL and Thymeleaf**. Designed for scalable, maintainable Java application development with clean Design and Architecture.

### ✨ Key Features

🎨 **Modular Templates:** Pre-built pages for home, product listings, user authentication, and admin dashboards

🔧 **Admin Management:** Add products & categories, manage inventory and content

🔐 **Secure Auth & Role-Based Access:** Admin / User roles, secure login

🛒 **User-Centric Features:** Shopping cart, search, filtering, detailed product views

📦 **Order Management:** Order processing with loading, empty & error states

🏗️ **Spring Boot Foundation:** Scalable backend with Controller -> Service -> Repository architecture

---

## 🛠️ Tech Stack

- **Backend:** Core Java, Java 8+, Java Classes, Java Collections Framework, Exception Handling, Logging, JDBC, I/O Package, Multithreading
- **Framework:** Spring Boot, Spring Data JPA, RESTful Webservices, Design Patterns
- **Frontend:** Thymeleaf, HTML5, CSS3, JavaScript (Field Editors)
- **Database:** MySQL / Oracle Database
- **Tools:** Maven, Git, JUnit, Mockito, Postman, Agile
